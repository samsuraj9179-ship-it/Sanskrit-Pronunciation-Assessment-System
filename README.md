The Sanskrit Pronunciation Assessment System is a Streamlit-based web application designed to evaluate the accuracy of spoken Sanskrit. It processes student audio input via microphone or file upload, extracts Mel-Frequency Cepstral Coefficients (MFCC) using Librosa, and compares them against native reference audio using FastDTW (Dynamic Time Warping). The project features a custom dark-mode glassmorphism UI with animated Devanagari particles, providing users with immediate pronunciation scores, normalized distance metrics, and visual acoustic feedback.
